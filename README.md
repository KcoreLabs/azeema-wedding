# Azeema & Bazeer wedding invitation

Static, responsive invitation from Azeema’s family. No installation or build required.

## Preview

Run `npm run dev`, then visit http://127.0.0.1:4173.

## Vercel

Import this folder’s Git repository into Vercel. Choose **Other** as the framework, leave the build command empty, and use `.` as the output directory. No environment variables are needed.

Content is in `index.html`, design in `style.css`, and the countdown and scroll reveals in `script.js`. The calendar event uses India Standard Time. Directions open a Google Maps venue search; replace its URL with the venue’s exact shared pin if available.

No RSVP or guest data collection is connected.
